推荐：让你自己的 coding agent 适配环境

这个包只保证「解压能跑」，但每个人的环境不一样——端口被占、公司代理、模型端点不是 DeepSeek、浏览器装在非默认路径、想改成开机自启。 最省事的办法是把解压出来的文件夹直接交给你自己的 coding agent， 让它照着 readme.md／使用说明.md 和 app/decision-desk/.env.example 针对你的机器做适配。代码是可读的 JavaScript，没有打包混淆，agent 改起来没有障碍。

把下面这段连同解压出来的文件夹一起交给它：

这是「看着办」Agent 工作台的离线包，已经解压在当前目录。请帮我在这台机器上跑起来：

1. 按 readme.md（或 使用说明.md）里的方式启动，运行时就在包内 runtime/ 目录，不要用系统里的 Node。
2. 如果 4317 端口被占用，改用别的端口（环境变量 PORT）。
3. 行为验证需要 Chrome / Chromium / Edge。先确认本机装在哪，装在非默认路径就用环境变量 CHROME_PATH 指过去。
4. 把 app/decision-desk/.env.example 复制成 app/decision-desk/.env，接上我的模型：需要 worker（执行）和 reviewer（独立审查）两个角色，走 OpenAI 兼容的 Chat Completions 接口。密钥我会告诉你，别写进任何会提交的文件。
5. 起来之后打开浏览器确认能新建任务并跑完一轮，有报错就直接排查。

一件要先知道的事

  • 行为验证需要浏览器。绿卡的证据来自真实浏览器里的行为检查，程序会自动找本机的 Chrome／Chromium／Edge，装在别处可用 CHROME_PATH 指定。找不到时会明确报告「没有可用浏览器」。
