# 运行中的模型设置同步

用户将执行和审查模型更新为 Flash 后，发现当前任务未同步。根因有两处：运行时仅在创建时复制全局设置；时间线的请求摘要使用任务创建时的 workerLabel，而非事件内实际请求的模型。

- 运行中保存的模型配置从下一次执行请求、下一次审查请求（包括重试）开始生效。每次请求使用最新已保存设置的独立快照，包含模型、接口、密钥与推理强度；不修改或取消已发出的请求，不重启任务，不改动要求版本。
- 新建、继续任务、追加要求后恢复运行均接入同一设置来源。注入测试适配器与测试审查器的机制保留。
- 任务的执行/审查模型标签在相应请求开始时更新。模型响应事件沿用该请求开始时的模型名称；历史请求摘要优先读取事件内 model，避免切换模型后改写历史或一直显示旧标签。
- 此次增加运行期间设置生效能力，范围只涉及模型配置的生效时点，不改变审查放行、约束门禁与工具执行规则。工程说明只保存在本笔记。
