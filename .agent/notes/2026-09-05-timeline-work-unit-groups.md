# 过程时间线按工作单元展开

用户要求减少顶层细节，按工作单元呈现，点开才查看最细 step。

- 顶层横向卡片展示工作单元目标、状态、步骤数量、时间及耗时；默认不展开内部记录。
- 点击单元后显示该单元事件时间线，保留步骤详情、人工判断/验证筛选和原始记录；再次点击或收起按钮关闭。新事件不会擅自打开其他单元。
- 优先用 unitId 和实际步骤/判断关联归组；只有在明确单元开始/结束区间内，才将无关联 ID 的模型、审查、工具、文件、验证事件归入当前单元。
- 无单元关联的全局记录单独收为“任务记录”；旧任务未声明过工作单元的记录收为“早期过程记录”，不伪造历史语义切分。原始事件不删除，内部工程纠错事件仍按既有规则隐藏。
- “已结束”仅表示单元关闭，不表示验证通过。本次仅更改前端呈现，无后端重启或任务语义变更。

验证：前端 11 项测试通过；隔离 Chrome 验证默认不展示细节、切换单元不混入另一单元事件、原始记录点击后才读取、收起隐藏细节。真实马里奥任务页面已加载总览，当时 3 个单元加任务记录，打开第一个单元只展示其 33 条内部事件，再收起恢复总览；原执行持续推进，没有重启服务。进行中单元耗时随时钟更新，已关闭单元使用实际关闭时间。
