# 欢迎页进入工作空间的连续过渡（2026-09-06）

此前欢迎页在离场动画结束后才卸载并首次渲染工作空间，同时用不透明中间层遮满屏幕；这会先出现一帧纯色，再硬切到主页。

现在停留在欢迎页时不会挂载工作空间。用户点击进入后，工作空间才会在固定纸张层下面绘制，并在纸张仍显示时保持 `inert` 和 `aria-hidden`；等待两个绘制帧后，纸张层在 420ms 内淡退，底层工作空间同时从轻微收束状态恢复，形成短暂重叠。动画结束后才更新 History API 路径并卸载纸张层。整个过程不重新加载页面，也没有新增依赖。

系统要求减少动态效果时，只等待一个绘制帧，不执行缩放或延时动画，直接显示已经绘制的工作空间。浏览器前进后退和待处理提醒仍可中断离场；组件卸载会清除计时器、绘制帧、根节点状态、Three.js/WebGL 和监听资源。纸张内部滚动保持冻结，滚动反向还原与 WebGL 降级路径不变。
