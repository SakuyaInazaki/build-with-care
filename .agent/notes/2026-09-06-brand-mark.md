# 看着办品牌图标

日期：2026-09-06

## 设计语义

品牌标志由四个开放的视框角和一笔判断线组成。开放视框表示产品持续观察 Agent 从执行到验证的过程；中间保留人的明确判断。图形不再使用原来的圆圈中心点，也不采用容易产生监控含义的眼睛。

中文名称“看着办”继续承担主要识别，图标保持克制。深色圆角方块沿用现有品牌承载面，让侧栏结构、对比度和点击区域保持稳定。

## 实现范围

- 新增集中 `BrandMark` SVG 组件，侧栏品牌入口使用同一图形。
- 新增同源 SVG favicon，在 16px 至 32px 尺寸保留相同开放轮廓与判断线。
- 设置角色、任务状态、头像、空状态等非品牌圆点与图标保持原语义。
- 候选比较与设计说明只保留在验收材料，不进入产品页面。

## 候选与选择

- A“开放视框”：负空间最多，小尺寸识别最好，作为最终方向。
- B“观察之眼”：语义直接，但更像监控并抢过中文名称。
- C“人在回路”：边界明确，但闭合结构更接近复选框或代码工具。
