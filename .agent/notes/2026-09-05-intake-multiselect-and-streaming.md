# 澄清多选、移除轮次小字和取消强制超时

用户再次要求落实可多选、也可只选一项，随后报告“需求澄清 · 第 2 题 / 最多 5 题”和“模型响应超过 45 秒，本次请求已停止”。此前记录不等于已经实现；本次明确实施。

- 澄清选项由 radio 改为独立 checkbox，可选一项、多项或取消选择。补充文本与选择并存，不再互相清空；也允许只填自由文本。换题或切换任务不沿用上一题选择。
- API 支持 choices 数组并核对它们属于本题。前端为兼容仍在执行用户任务的旧服务，将全部选择和补充组合进原 answer 字段，旧服务也能读取全部选项。新服务将 answer 接收上限扩至 12100，容纳四个最长选项与 4000 字补充；旧服务仍有 4000 字总上限，超过会明确报错而非截断，直至更新服务。答案原样传给澄清模型并保存进回答历史。
- 澄清提示取消强制互斥选项，支持组合选择；确有冲突要澄清或列为未决，不得悄悄丢弃某项。仍保留单题、最多五轮、最终人工确认等业务门槛。
- 移除澄清面板的轮次/上限小字及配套圆点，不新增产品设计解释文案。
- 根因：`nextGrill` 仍调用非流式 complete 并显式传入 45000。改用与审查共用的原生 SSE completeStream，完整汇总后解析 JSON，无固定总截止时间。页面等待完整问题后显示，不把未完成 JSON 当问题发布。实际网络/服务错误仍返回错误，原回答保留供重试。

部署等待实际澄清请求和执行请求结束，不能为了加载修复而中断它们。

验证与交付：后端 59 项回归、前端类型检查与构建通过；隔离 Chrome 回归验证多选/单选/自由输入、取消勾选、失败保留、换题清空。前端生产资源已更新并加载，答案使用原 answer 字段兼容旧服务。当前马里奥任务已进入执行，实际后端仍为 `unified-work-units-v1`；取消澄清 45 秒截止和新提示词尚未加载，不能称其已上线。此处等待安全更新，不停止当前任务。
