# 时间线完整记录与卡片底色

用户追加反馈：原始记录只有几行，缺少有用信息；决策看板的四种颜色过浅，卡片底色仍是白色。

- 原始记录按需加载完整事件及其关联动作，包含完整工具参数、结果、审查事件、门禁与验证结果；模型调用关联实际响应耗时、输入/输出 token、模型名称、最终正文和工具调用。推理只显示实际字符数，完整推理仍保留在原始 dsh 记录文件中。历史与当前关联状态分别以 event 和 action 表达，不改写原始事件。
- 使用事件时间区间关联原始模型响应，避免服务重启后 dsh 序号重置造成串线。缺失响应返回空，不虚构请求或用量。继续排除内部工程修复事件。
- 卡片按既有 red / blue / neutral / green 语义分别使用明显的红、蓝、灰、绿底色，配同色系深色正文与边框；保留原文字状态、图标和选中反馈，不改变决策分类或验证结论。没有增加新的颜色类别。
