# 看板等高与状态底色

用户指出展开与收起的栏高度不同、轮廓突兀，并再次要求更明显的颜色。原 `.board-lane.is-collapsed` 将最小高度改为 auto，叠加 grid 顶部对齐导致折叠栏缩成标题；除红栏以外的栏底色共用近白灰，卡片色也过浅。

本次四栏采用相同、随视口有上下限的固定高度与纵向 flex 布局；折叠只隐藏卡片内容，标题、计数与栏的外轮廓保持不变；展开内容在剩余空间独立滚动。移除导致不同高度的折叠及窄屏覆盖规则。

红、蓝、灰、绿四栏分别使用明确的实色底色，卡片使用更深一阶底色与相应深色文字，空状态和计数同步提高对比度。状态语义、卡片归类、人工判断及验证规则不变，无新增页面解释文案。

本次仅构建前端静态资源，无需重启后端，也不触发任务执行。

验证：生产构建通过。真实 Chrome 页面展开/收起互换后四栏实测均为 482.98px；10 张等待验证卡片在约 415px 的内部区域滚动。实际样式已加载红/蓝/灰/绿实色栏底与更深卡片，正文和标签统一使用对应深色文字，四种卡片文字对比度为 6.24–6.90:1。操作不修改任务状态。此记录更新此前合并记录中折叠时栏缩短的视觉行为。
