# 视频技能本地副本

这里保存 2026-09-06 本机已安装视频技能的可复用源码、说明、脚本、模板和资源，便于项目内查阅与后续使用。

来源项目：

- HyperFrames：[heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)，包含 `hyperframes`、`hyperframes-animation`、`hyperframes-audio`、`hyperframes-cli`、`hyperframes-core`、`hyperframes-creative`、`hyperframes-keyframes`、`hyperframes-registry` 和 `media-use`。
- video-use：[browser-use/video-use](https://github.com/browser-use/video-use)。
- video-shotcraft：[Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)。

副本保留源目录中已有的许可证文件。许可证与使用条件以各来源项目及目录内文件为准。

本目录没有打包 `node_modules`、Python `.venv`、缓存、构建输出、生成视频或本机密钥配置。离线使用涉及 Node.js 或 Python 包的功能时，仍需按各技能自己的安装说明准备依赖。

配套研究文档位于 [`docs/苹果产品与软件宣传片风格调研.md`](../../docs/苹果产品与软件宣传片风格调研.md)。
