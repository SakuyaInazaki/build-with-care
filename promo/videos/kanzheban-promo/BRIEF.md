## Intent

为「看着办」（Build with Care 黑客松 · 赛道三「给 Multi-Agent 时代构建一个人仍然在场的工作台」，
出题方 知是 CheeseX）制作一支 90 秒产品宣传片。

主张只有一条，且必须被画面证明：**你说的话，一直在场。**
不是"AI 更聪明了"，而是"你确认过的要求，在 Agent 落笔之前被对照了一次"。

气质对齐苹果软件介绍片（Liquid Glass / Dynamic Island 一路）：克制、正面、稳定构图，
让一个对象连续变化，而不是靠特效堆叠。产品本身是浅色纸感界面，片子不另起一套渐变。

## Assets

- capture/screenshots/ — 本机运行真实产品（http://127.0.0.1:4488）截取的真实界面，
  含：任务概览、决策看板四栏、卡片双栏详情（你的要求 v3 / Agent 的行动）、
  过程时间线、成果与验证（真实产物预览 + 验证证据）、我的判断（10 次判断 / 8 次纠正）。
- 数据来源为真实完成的任务「帮我构建一个网页版超级马里奥」，非虚构演示数据。

## Customizations

- 无旁白配音（本机无 TTS 授权，且用户选择先出无声版）。信息由中文字卡 + 真实 UI 文字承担。
- 先交付无声成片 + 一份卡点表（标明每个音乐事件应落在第几秒），音乐后定。
  音乐方向已定：极简钢琴 + 低频脉冲；红卡拦停处音乐留白一次，结尾一次落定和弦。
- 贯穿对象：「你的要求 v3」。它在需求确认段建立，在每个 Agent 动作段被对照，
  在结尾收束进「我的判断」报告。全片不得让这个对象在转场中丢失身份或位置。
- **分层堆叠 + 斜视角（用户 2026-09-06 追加要求，全片结构主干）**：
  产品被拆成一摞可分离的平面，按产品自己的工作顺序逐层叠上去，用透视展示层级关系。
  层序：L0 工作台画布 → **L1 你的要求 v3（最底板，全片不撤）** → L2 工作单元时间线 →
  L3 决策卡 → L4 对照双栏 → L5 闸口拦停 → L6 验证证据 → L7 产物。
  语义：一切都叠在"你说过的话"上面，被它托着；片尾上层全部清空，只剩 L1 翻正成报告。
  机位：展示层级/堆叠/前后关系时用斜视角（rotateX 14–20° / rotateY −12°）；
  **需要阅读中文正文或 UI 文字时必须 tilt-to-flatten 回正到 0° 并稳定**——
  这是调研文档 §5 的硬规则（"需要阅读的 UI 长时间大角度倾斜"列为误用），不是可选项。

## Notes

- 诚实边界（不可违反）：不得暗示已接入真实多模型异源判官、不得暗示磁盘回滚、
  不得把演示速度包装成实测性能。画面中出现的一切 UI 状态必须来自真实运行数据。
- 首版只公开 forward-only；不出现 fork/branch/回滚画面。
- 绿色只能由受控执行器证据产生——"已验证"栏与"验证证据"清单可以出现，
  但不能配"AI 自己说没问题"这类文案。
- 中文标题按语义块排布，不套英文逐词闪现。
- 不使用 Crush! 式"压缩/摧毁"隐喻——本片主题是人保留判断权，隐喻不能让人感到人被消除。
