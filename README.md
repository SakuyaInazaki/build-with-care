# Build with Care · 在场

让人的要求、Agent 的选择和实际执行结果可以逐步对照。当前应用位于 **[decision-desk](./decision-desk/)**，原有需求、调研与 POC 保留在仓库中。

## 运行应用

需要 Node.js 24+ 和 pnpm 11：

```sh
cd decision-desk
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

打开 <http://127.0.0.1:4317>。Windows 也可双击 `decision-desk/启动.cmd`。

- 双栏时间线对照人的要求与 Agent 行动，事件按颜色分类并支持筛选。
- 明确冲突在文件改动前暂停；支持纠正、仅本次放行和停止。
- 随时追加新要求或参考想法，已完成任务可继续；人工输入留在时间线和复盘中。
- 成果独立宽屏展示，支持全屏、独立页面与实际交互。
- 文件、检查和人工判断形成可导出的记录；旧内容变化后，对应检查失效。

交互演示无需密钥，使用明确标识的脚本执行器和规则审查，底层 dsh 调度与文件写入是真实执行的。真实运行模式支持独立配置执行模型与异源审查模型；尚未进行外部真实模型质量评估。
