# 看着办 · 离线包使用说明

解压后就是完整的程序，不需要编译，也不需要 `npm install`。

## 运行

按你的系统下载对应的包，解压后：

| 系统 | 压缩包 | 操作 |
|---|---|---|
| macOS（Apple 芯片） | `看着办-vX-macos-arm64.zip` | 双击 `启动.command` |
| macOS（Intel） | `看着办-vX-macos-intel.zip` | 双击 `启动.command` |
| Windows | `看着办-vX-windows-x64.zip` | 双击 `启动.cmd` |
| Linux | `看着办-vX-linux-x64.zip` | 终端执行 `./start.sh` |

浏览器会自动打开 <http://127.0.0.1:4317>。换端口：先设环境变量 `PORT`。

**不需要装任何东西。** Node 运行时（v24.20.0）就在包里的 `runtime/` 目录，程序用的是它，不碰你系统里的 Node，也不会去改你的环境。全部依赖都已随包分发，运行时不联网下载任何内容。

macOS 首次双击如果提示"无法验证开发者"，在「系统设置 → 隐私与安全性」里点「仍要打开」；或者在终端里执行 `xattr -dr com.apple.quarantine <解压出来的文件夹>`。

## 数据放在哪

所有会话记录写在压缩包同级的 `我的记录/` 目录里，纯本地文件，不上传任何地方。删掉这个目录就等于清空。

## 两种运行方式

**演示模式**（默认，开箱即用）：不调用任何模型，执行器走内置剧本。四色决策卡、双栏对账、时间线回放、一页报告都是真实产生的，可以完整走一遍流程。

**真实模型模式**：需要自己的模型密钥。

1. 把 `app/decision-desk/.env.example` 复制成 `app/decision-desk/.env`
2. 填入 `DEEPSEEK_API_KEY`（或按文件里的说明配置任意 OpenAI 兼容接口）
3. 重新启动

也可以启动后在界面的「模型设置」里直接填，配置保存在本机。

## 行为验证需要浏览器

绿卡的证据来自真实浏览器里的行为验证。程序会自动寻找本机的 Chrome / Chromium / Edge；如果装在非默认位置，用环境变量 `CHROME_PATH` 指定可执行文件路径即可。找不到浏览器时，验证会明确报告「本机没有可用的 Chrome／Chromium」，**不会伪造成通过**。

## 边界

- 真实模型模式下，`run_command` 会在你的机器上直接执行任务自带的 `package.json` scripts，**没有操作系统级隔离**。只对你信任的任务使用这个模式。
- `rewind-and-fork` 是逻辑分叉，不回滚磁盘文件；已经发生的外部副作用无法撤销。
