# 在场｜Agent 过程对账台 · 项目说明

> 赛道三「给 Multi-Agent 时代构建一个人仍然在场的工作台」· 出题方 知是 CheeseX · 2026-09-06 提交

## 问题：那个人跟不上 Agent 的时刻

一句话需求交给 agent，回来是 600 行 diff：数据库选型、鉴权方式、目录结构全被它替你定了，你只在写完之后才发现哪个错了。人读代码的检出率过几百行就断崖下跌，"审"退化成盖章；多 agent 时错误还会层层放大。

赛题原文："人还在场"指两件事：**这一刻他管得住 Agent，一年之后他自己也变强了。第二件事没有第一件显眼，但它才是出这道题的原因。** 我们抓的时刻，就是决定正被 agent 静默拍板、人还来得及说"不"的那一秒；我们沉淀的，是人在这些时刻做了哪些判断。

## 为谁

- 用 agent 写代码的学生团队：只想看"它替我定了什么"，不想读 diff。
- 非技术验收人（产品、老师、助教）：卡片是中文判断题，不是代码。
- 教学与作品集场景：会话报告区分"人的判断"与"agent 自主拍板"，可作过程证明。

## 怎么解决：决策流 + 对账 + 报告

1. **短 spec 先确认**：一句话需求扩成 2–4 条约束，人确认后开工；它是判色基线。
2. **四色决策卡**：红 = 与 spec 冲突，执行前阻断，必须裁决（放行 / 备选 / 改写 / 叫停）；蓝 = agent 自主拍板，不阻断，进侧栏，随时可事后翻案；灰 = 纯执行只进日志；绿 = 只有 executor 绑定的验证证据通过才转绿，人工复核不冒充绿。
3. **双栏对账**：每一步"人说了什么 / Agent 实际做了什么"，由独立判官判色、异源记录员标出"自作主张"与"与指令不符"——不信干活 agent 的自报。
4. **两种纠偏，都保留历史**：forward-only 翻案只向前生效，不回滚已完成工作；rewind-and-fork 从已完成 turn 边界开新分支，原分支暂存可对比。
5. **失败升级求助**：运行报错自修 3 次仍败即升级为阻塞求助；审批倒计时超时 fail-closed，不放行。
6. **时间线回放 + 一页报告**：多 agent 合并的 append-only 时间线；结束会话自动汇总：人判断几次、agent 自主拍板几次、其中几次纠正了方向，附翻案前后对比。

## 与已有产品的差异

- CodeRabbit / review packet 事后翻译 diff；我们在**改动发生之前**截住决策点。
- Cursor Blame / agentblame / git-ai 归因代码行；我们**归因人的干预**——不判断即无贡献。
- LangGraph time-travel / Claude Code rewind 回滚即丢下游工作；我们两种纠偏模式都**保留原时间线**。

## 赛道边界 → 产品机制

| 赛道要求 | 产品机制 |
|---|---|
| 把人拿掉，核心流程不应还能跑 | 红卡 gate 无人裁决即挂起，超时 fail-closed 取消，永不自动放行 |
| 人在哪里看 | 双栏对账、蓝卡侧栏、全局时间线回放 |
| 人在哪里拍板 | spec 确认、红卡四档裁决、蓝卡事后翻案、求助升级 |
| 人在哪里被证明 | 会话报告：人的判断 vs agent 自主拍板，附前后对比 |
| 区分人的判断与 agent 执行 | 每条事件带来源：human / judge / recorder / executor / agent |

## 边界诚实声明

- rewind-and-fork 是逻辑 fork，不回滚磁盘文件；邮件、网络请求等外部副作用不可撤销，界面明示。
- 未配置模型时，判官与记录员为规则实现，"完整演示"由服务器脚本驱动；配置后切换真模型，卡片 provenance 标明来源。
- DeepSeek Harness 已真实接入：`@deepseek-ai/dsh-*` 0.1.2-rc.1，工具注册、agent loop、会话投影都走 dsh 运行时，不是 mock。
- 真实模型模式下 `run_command` 直接在宿主机执行任务自带的 `package.json` scripts，**没有操作系统级隔离**；公开演示站因此禁用该模式，文档与界面都不把它称作沙箱。

## 三种运行方式

| 方式 | 命令 | 说明 |
|---|---|---|
| 公开演示站 | 打开链接即可 | 无需安装，开箱走完整流程；共享环境、只跑内置剧本 |
| 免安装离线包 | 解压后双击 `启动.command` / `启动.cmd` | 需要 Node.js 24+，其余依赖已打包；支持配置自己的模型密钥 |
| 从源码运行 | `pnpm --dir decision-desk install --frozen-lockfile && npm --prefix frontend ci && npm run build && npm start` | 打开 <http://127.0.0.1:4317> |
