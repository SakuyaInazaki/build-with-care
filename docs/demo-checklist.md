## D. 可能出错的事与对策

| 风险 | 表现 | 对策 |
|---|---|---|
| 审批倒计时 | pending 红卡默认 10 分钟无人裁决即 fail-closed 取消 | 上台前不要启动场景；候场时页面停在 spec 未确认状态。若彩排时红卡被取消，直接新会话重跑 |
| 服务重启 | 重启后 pending gate 变为 `interrupted`，无法继续 | 中途崩溃不要重启接着演，改切录屏；崩溃后重开必须新建会话 |
| 演示 runner 冲突 | 同一会话已有 runner 在跑再点启动 → 409 | 一场只点一次启动；误点就新会话 |
| 会场没网 | 真模型层不可用 | 页面无 CDN 依赖，服务只绑 127.0.0.1，第 2 层完全离线可跑；手机热点作真模型层备份 |
| 投影缩放 | 页面在视口宽度 < 980 CSS px 时变单列，侧栏蓝卡会掉到下面 | 1920 宽投影：缩放 ≤ 175%；1366 宽投影：缩放 ≤ 125%。上台前按 ⌘0 复位再调一次 |
| 窗口尺寸 | 页面主体最大宽 1440px，居中 | 浏览器窗口设 1920×1080 全屏；时间线与侧栏是内滚动区，彩排时记住红卡出现的位置要不要滚 |
| 打印对话框 | 「打印一页报告」调用 window.print()，系统对话框盖住投影 | 路演只看屏幕上的报告，不点打印；误点按 Esc。提交用的 PDF 赛前另存 |
| 会话下拉框杂乱 | 旧彩排会话堆在列表里 | 用 `DECISION_STREAM_DATA` 指向干净目录（见 B） |
| 端口占用 | 4173 被上一个进程占着 | `lsof -i :4173` 杀掉，或 `PORT=4174 npm start` 并同步改浏览器地址 |
| SSE 断开 | 卡片不实时刷新 | 前端应自动退化为 1.5 秒轮询；若没动静，手动刷新页面（会话状态在服务端，不丢） |
| 蓝卡看不见 | 蓝卡不弹窗，评委没注意 | 台词里用手指侧栏；缩放确保侧栏在首屏 |
| 自由改写输入法 | 中文输入法在改写框弹候选窗 | 路演只点备选按钮，不打字 |
| 结束会话后再操作 | session 冻结，执行类请求 409 | 报告出来就停手，不再点任何卡 |
